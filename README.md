**Skyridge Courier** — a bush pilot flight game over a volcanic island chain. Take off from Merpati Field, thread 8 gold rings down the valley, and put her down gently on Kelud Strip — or just fly free and mind the fuel gauge. Chase view over recognisable terrain, the aircraft in frame with lit instruments, a runway ahead, and altitude, speed and heading on the HUD. Keyboard and mouse, no build step, no network: plain static files under `game/`.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```

Or serve `game/` with any static file server and open `index.html`.

## How to fly

- **↑ / ↓** pitch · **← / →** bank · **Shift / Ctrl** throttle · **mouse** steers · **wheel** throttle
- **G** gear · **F** flaps · **B** brake · **P** pause · **M** mute · **R** restart
- **1 / 2 / 3** pick a mission from the menu

## Missions

1. **Ring Run** — thread all 8 gold rings in order (500 pts each + speed bonus, +5% fuel per ring), then land.
2. **Island Hop** — take off from Merpati Field and land on Kelud Strip; landing quality pays up to 2,000 pts.
3. **Free Flight** — no orders. Explore, chase rings, land anywhere flat.

Fuel burns with throttle, a stalled wing drops the nose, and a hard arrival is a crash — a gentle touchdown with the gear down is a landing.
